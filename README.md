# Monit
YBIGTA 산학 산출물


A. 주요 기능

1. 지능형 경로 탐색: 출발지, 도착지, 최대 3개의 경유지를 포함하는 다이나믹 경로 설정

2. 최적 충전소 추천: 경로의 특징(고속도로/일반도로)에 따라 가변적인 간격으로 충전소를 추천하고, 상세 필터(충전 속도, 타입, 운영사) 제공

3. AI 여행 플래너: 장거리 여행 시, 사용자의 관심사와 리뷰 데이터를 기반으로 AI가 상세한 여행 일정을 자동 생성



B. 프로젝트 워크플로우

1. 데이터 준비 단계(통영) - Offline

리뷰 데이터 수집 (googlemaps_crawler.py): Selenium을 이용해 구글맵에서 특정 지역(통영)의 관광지 및 음식점 리뷰 텍스트를 크롤링.

리뷰 데이터 분석 (review_analysis.py): 수집된 텍스트 리뷰를 OpenAI GPT 모델에 전달하여, 정해진 기준(노인/장애인 접근성, 주차, 키워드 등)에 따라 점수와 요약을 추출하는 구조화된 데이터로 변환.

충전소 데이터 전처리 (data_prep.py): 공공데이터 포털의 '충전기' 단위 데이터를 '충전소' 단위로 그룹화하고, working_ratio(실제 작동률), congestion_ratio(혼잡도) 등 분석에 필요한 핵심 지표를 계산하여 저장.

2. 사용자 서비스 단계 - Online (main.py)

경로 입력: 사용자가 Streamlit UI를 통해 출발지, 도착지, 경유지를 입력합니다.

경로 분석: 카카오내비 API를 통해 경로 데이터를 수신하고, 총 거리와 고속도로 포함 여부를 분석하여 '장거리 여행' 여부를 판단.

충전소 추천: 경로상에 최적의 충전소를 추천하고 지도에 시각화.

AI 일정 생성: '장거리 여행'일 경우, 사용자는 AI 플래너를 활성화.

일정 수정 및 확정: 생성된 일정을 채팅을 통해 수정하고 최종 계획을 확정.

C. 핵심 알고리즘 구현 방식

1. 경로 분석 및 추천 지점 추출 알고리즘
경로상에서 충전소를 추천할 최적의 지점을 효과적으로 찾아내기 위해 '가변 간격 좌표 추출' 알고리즘을 구현.

구현 위치: utils/map_utils.py의 extract_variable_interval_points 함수

작동 방식:

카카오내비 API로부터 받은 경로의 모든 좌표 세그먼트를 순회하며 누적 거리를 계산.

도로의 종류(road_type)가 '고속도로'인지 '일반도로'인지 지속적으로 확인.

도로 종류에 따라 미리 설정된 간격 기준(current_interval)을 다르게 적용. (예: 고속도로 50km, 일반도로 5km)

누적 거리가 현재 간격 기준을 초과할 때마다 해당 지점의 좌표를 '추천 지점'으로 추출하고, 다음 목표 거리를 업데이트.

고속도로 진입/진출 지점은 간격과 무관하게 항상 추천 지점에 포함.

2. 충전소 추천 및 스코어링 알고리즘
추천 지점 주변의 수많은 충전소 중 사용자에게 가장 적합한 곳을 선정하기 위해 '다단계 필터링 및 가중치 기반 스코어링' 모델을 사용.

구현 위치: utils/charger_recomm.py의 run_recommendation, scoring.py의 filter_* 및 score_stations 함수

작동 방식:

1차 필터링 (기본 조건): 추천 지점 주변의 모든 충전소 중, 현재 운영 중(working_ratio > 0)이며 최근 사용 기록이 있는 신뢰도 높은 충전소만 유지.

2차 필터링 (거리 기반): 1차 필터링을 통과한 충전소들을 대상으로, 추천 지점 반경 N km 이내에 있는 곳만 유지. (NumPy를 활용한 벡터화된 Haversine 공식으로 빠른 연산 수행)

3차 필터링 (사용자 맞춤): 사용자가 UI에서 선택한 상세 조건(충전 속도, 커넥터 타입, 운영사 등)에 맞는 충전소만 최종 후보로 선정.

스코어링: 최종 후보들을 대상으로 점수를 계산합니다. 각 요소에 가중치를 부여하여 총점을 계산하는 방식.

Positive Factors (+): working_ratio(작동률), is_free_parking(무료 주차) 등

Negative Factors (-): distance_km(거리), congestion_ratio(혼잡도) 등

계산된 total_score가 가장 높은 순서대로 Top-K (기본 3개) 충전소를 최종 추천.

3. LLM 기반 리뷰 데이터 분석 알고리즘
정형화되지 않은 대량의 텍스트 리뷰에서 유의미한 정보를 자동으로 추출하기 위해 '프롬프트 엔지니어링 기반 정보 추출' 방식을 사용합니다.

구현 위치: review_analysis.py

작동 방식:

추출하고자 하는 정보(노인/장애인 접근성 점수 및 사유, 주차 문제, 핵심 키워드 등)와 원하는 출력 형식(CSV 한 줄)을 명시한 PROMPT_TEMPLATE.

크롤링한 모든 리뷰 텍스트를 하나의 문자열로 합쳐 프롬프트 템플릿에 삽입.

정보가 포함된 최종 프롬프트를 OpenAI GPT-4o-mini 모델에 전달.

AI는 지시에 따라 텍스트의 맥락을 분석하고, 요청된 형식에 맞춰 구조화된 데이터를 반환합니다. 이 과정을 통해 비정형 텍스트를 정형 데이터베이스로 자동 변환.

4. AI 여행 일정 생성 및 수정 알고리즘
사용자 맞춤형 일정을 생성하고 유연하게 수정하기 위해 '데이터 증강 생성(RAG) 및 대화형 수정' 알고리즘을 활용.

구현 위치: main.py의 AI 플래너 섹션, utils/ai_planner.py

일정 생성 (데이터 증강):

단순히 "맛집과 자연경관을 포함해줘"라고 요청하는 대신, (1) 사용자의 선호사항과 (2) 사전에 분석된 리뷰 데이터(상위 5개 맛집/관광지 목록)를 함께 조합하여 프롬프트를 구성합니다.

이처럼 구체적인 데이터를 함께 제공함으로써, Google Gemini 모델이 막연한 정보가 아닌 실제 데이터를 기반으로 구체적이고 만족도 높은 일정을 생성하도록 유도.

일정 수정 (대화형 세션):

일정 생성 시 model.start_chat()을 통해 생성된 채팅 세션(chat)을 유지합니다.

사용자가 "첫째 날 점심을 다른 곳으로 바꿔줘"와 같은 수정 요청을 하면, 이 요청은 독립적인 질문이 아니라 기존 대화의 맥락 안에서 Gemini에게 전달.

이를 통해 AI는 이전에 생성했던 일정과 대화 내용을 기억하고, 맥락에 맞는 수정안을 제시할 수 있습니다.

수정된 내용이 포함된 새로운 JSON을 AI가 반환하면, 앱은 이 데이터를 파싱하여 화면의 일정표와 지도를 즉시 업데이트합니다.
